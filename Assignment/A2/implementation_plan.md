## 1. Agent decision rules `agent.py`

每一个agent占据一个位置sij in S

每个 agent 是一个观众，行为状态是二元的：

- s_{ij}^t = 1：站立
- s_{ij}^t = 0：坐着

agent的行动分成两个阶段:  
第一阶段是 **initial decision（初始决策）**。表演结束后，每个观众根据自己接收到的质量信号 q_{ij} 决定是否立即站起来。每个 agent 有一个站立阈值 T_{ij}。如果：  
q_{ij} \geq T_{ij}  
则该 agent 在 t=0 时站起来；否则保持坐着。论文的具体计算模型中，所有 agent 使用相同阈值 T=0.5，质量评价 q_{ij}\in[0,1]。  

第二阶段是 **social updating（社会更新）**。初始站立发生后，agent 不再根据自己的质量评价，而是根据可见邻居的行为更新。论文采用 **majority rule heuristic（多数规则启发式）**：如果 agent 看到的邻居中多数人站着，她就站起来；如果多数人坐着，她就坐下；如果平局，则随机坐或站。

也就是说，agent 的行为规则可以概括为：

- 初始阶段：私人质量评价 + 阈值规则
- 后续阶段：局部多数模仿规则

## 2. Model architecture `model.py`

空间结构是一个 **rectangular auditorium（矩形剧场）**。总共 400 个座位，也就是大致可以理解为 20 \times 20 的二维座位网格。每个 agent 固定在一个座位 (i,j)，其中 i 表示 row，j 表示 seat。
agent 的可见范围由 **neighborhood structure（邻域结构）** 决定。neighborhood structure允许两种可能的选项：  

1. **five-neighbor structure（五邻居结构）**。每个 agent 可以看到左右两边的两个邻居，以及前方一排的三个邻居。形式上接近：

FFF
FXF

其中 X 是当前 agent，F 是可见邻居。

1. cone neighborhood（锥形邻域）。agent 可以看到左右两边、前方一排的三个座位、前方两排的五个座位，以此类推，形成一个向前展开的视野锥。这个设定使前排观众具有更强的信号影响力，因为他们能被更多人看到。

activation / updating 方面，允许三种可能的机制：

1. synchronous updating（同步更新）：每个离散时间步开始时，所有 agent 同时更新。
2. asynchronous-random updating（随机异步更新）：每个时间步中，agent 被随机排列，然后按随机顺序逐个更新。
3. asynchronous-incentive-based updating（基于激励的异步更新）：agent 不是随机更新，而是根据激励顺序更新。具体来说，那些与周围人行为最不一致的 agent 最先更新。作者认为这个可能更接近现实，因为最不协调的人最有压力改变行为。

模型终止条件是达到 steady state（稳定状态），即观众状态不再变化，或者宏观上稳定。

需要提取的参数：(data collector)

1. stand_proportion (多少比例的人站着)：用于判断系统是否收敛。
2. if_stable: 一个变量 判断是否收敛(站立人数不在发生变化）
3. N_iteration  if if_stable =True, 此刻的trial number; 否则None
4. “Stick in the Muds”：最终(if_stable=True)与多数人行为相反的人所占比例 (单纯是看收敛状态下的比例)
5. Information efficiency：最终多数行为是否与初始多数行为一致 (收敛状态vs.初始状态)

1. 理想 GUI 的各个 component 构想

理想的 GUI 应该有一个主要的空间可视化区域，用来显示整个剧场座位网格。每个格子代表一个观众。格子的颜色、图标或状态标记表示该 agent 当前是坐着还是站立。剧场前方应该被清楚标出，因为前排观众的可见性和信号影响力是这个模型的核心机制之一。

这个空间可视化区域还应该能展示 agent 的局部视野。例如，当用户选择“五邻居结构”或“锥形邻域”时，点击或悬停在某个 agent 上，界面可以高亮显示该 agent 能看到哪些其他观众。这样可以直观展示模型的核心机制：个体只基于局部可见信息进行多数模仿，但这些局部规则最终会产生全局性的起立鼓掌或失败的 ovation。

GUI 至少应该包括一个动态结果图。最重要的图是 (S_t)，即每个时间步中站立人数或站立比例的变化曲线。这个图可以直接显示 ovation 是扩散、消退、振荡，还是最终稳定。另一个有用的图是不同实验条件下的信息效率，也就是最终多数行为是否反映初始多数行为。这个图能对应论文的关键发现：更新时间机制和邻域结构会影响集体结果是否有效聚合初始信息。

输入控制区应该允许用户调节所有变量参数。最基本的控制项包括：剧场行数、剧场列数、初始站立阈值、质量信号分布、邻域类型、更新机制、平局处理方式、随机种子和模拟速度。更高级的控制项可以包括：阈值异质性、顽固 agent 的比例、后续决策中私人偏好的权重，以及是否加入“托儿”或固定站立 agent。

1. Potential challenges, implementation choices, and judgment calls

主要实现困难包括：

第一个困难是如何精确实现邻域结构，尤其是在边界位置。靠近墙边、第一排或最后一排的 agent 会有更少的可见邻居。因此，模型需要决定：只计算实际存在的可见座位，还是对边界进行某种标准化处理。

第二个困难是如何实现“基于激励的异步更新”。论文说那些与周围人行为最不一致的 agent 会最先更新，但这需要定义一个具体的“不一致程度”。一种自然做法是计算 agent 的可见邻居中有多大比例采取了与自己相反的行为，然后按照这个比例从高到低排序更新。这是合理的，但仍然是一个实现选择。

第三个困难是停止条件。同步更新可能产生循环，例如一些 agent 在站立和坐下之间反复切换，而不是进入固定状态。论文报告的是到达稳定状态所需的迭代次数，但具体实现中需要决定如何检测循环，或者是否设置最大迭代次数。

论文描述中需要自行解释或操作化的模糊之处包括：

首先，初始质量信号 (q_{ij}) 的分布没有被完全明确说明。论文只说它位于 ([0,1]) 区间内。一个自然的实现方式是使用 Uniform(0,1)，但这仍然是一个建模选择。

其次，锥形邻域的几何结构需要被精确转化为代码。比如 agent 向前最多能看到多少排？每向前一排视野是否严格增加两个座位？靠近边界时如何截断？这些都需要具体规定。

第三，“可见邻居中的多数”也需要操作化。需要决定分母是否只包括实际可见的座位，是否忽略越界位置，是否排除 agent 自己。根据论文图示，合理解释是只计算实际存在的可见邻居，并且不包括自己。

最后，论文中从 (t=0) 的私人质量评价决策，突然转向 (t>0) 的纯社会多数规则，是一个非常强的简化。更心理学上真实的版本可能会让 agent 在后续阶段仍然保留一部分私人偏好权重。但如果目标是忠实复现论文模型，就应该先保持这个极端设定；如果目标是扩展模型，则可以把私人偏好权重作为额外参数加入。
